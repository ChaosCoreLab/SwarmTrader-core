## Problem
In cycle 010 the review's rendering scripts and the guide's integration scripts lived in the session scratchpad and were not kept ([[approximate-jekyll-render-without-ruby]]; the guide's work folder later had to be partly recovered): a later correction cannot regenerate a table it cannot rerun. Cycle 011 took "work scripts in a persistent folder outside `/tmp`" as a lesson of cycle 010 (Step 1, AC-09).

## Solution
A work folder **outside `/tmp` and outside the repository**, one per research issue (cycle 011: `/home/luca/Workspace/swarmtrader-r2-work/`; cycle 010: `/home/luca/Workspace/swarmtrader-guide-work/`), with fixed roles:

| Folder | Content | Who writes |
|---|---|---|
| `dataset/` | generator of the example dataset that **fails** if it diverges from the source table (the guide's 20 days) | author |
| `ref/` | implementations (each indicator incremental and direct, checked equal bar by bar), identities, correlations, examples, `check-doc.mjs` | author |
| `out/` | generated tables; the document's data tables must be identical to them | author's scripts |
| `verify/` | independent recomputation, written without reading `ref/` ([[clean-room-recomputation-other-language]]) | verifier |
| `reviews/` | reports of the simulated readers ([[two-round-independent-simulated-reading]]) | readers |

`check-doc.mjs` is re-run after every correction: no Liquid openers, code lines <= 80 columns, column count per table, links, data tables equal to `out/`, every number in the text traceable, required boxes per card, a reading sentence before each table, references all defined and cited. Exploratory numbers computed in the scratchpad by earlier steps (Explorer, Critic) are never cited: they are regenerated in `ref/`.

## Example
Cycle 011 (catalog `docs/architecture/genome-indicators-catalog.md`): 68 incremental = direct checks, 21 data tables equal to `out/`, `check-doc` 10/10 after each of three correction rounds.

## Known limitations
- The folder is not versioned: the document says where its numbers come from, but a clean clone cannot rebuild them. Moving the scripts into the repository is a decision not taken.
- Paths are machine-specific (Ubuntu workstation).
