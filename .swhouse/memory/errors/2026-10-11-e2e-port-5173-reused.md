## What happened
`npm run test:e2e` failed 10/10 ("element(s) not found", `#run-state`) on the Ubuntu workstation, also on code with no changes. The page Playwright opened was "Tabellone Pallavolo Live", another project listening on port 5173. `playwright.config.js` sets `reuseExistingServer: !process.env.CI`, so it reuses whatever answers on the port.

## How it was handled
A temporary copy of the config with another port (5199) ran the suite: 10/10 pass. The other process was left alone.

## Prevention
Before trusting an e2e result, check `curl -s http://127.0.0.1:5173/ | grep -o '<title>[^<]*'`. Open proposal (cycle 009, Step 11): make the port configurable or stop reusing a server that is not this project's.
